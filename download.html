Desco

Closed beta

Grab the latest signed & notarized build. Desco is currently in a closed beta — you'll need the access password we shared with you to open it. An open beta is coming soon.

Download the latest beta →

Requires macOS 13 (Ventura) or later, Apple silicon or Intel. On the release page, download the .dmg.

Install

1. Open the downloaded .dmg and drag Desco to your Applications folder.

2. Launch Desco. It runs in the menu bar — there's no Dock icon.

3. Enter the closed-beta password when prompted.

The build is notarized by Apple, so Gatekeeper opens it without warnings. Updates arrive automatically in-app.
