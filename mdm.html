Deploying Desco licenses with MDM

IT admins can activate Desco on many Macs without touching each one. Buy a license (for example Company, 100 Macs), then push the key in a configuration profile. Desco activates silently the next time it launches.

Steps

  1. Download the example profile: desco-license.mobileconfig.
  2. Replace PUT-YOUR-LICENSE-KEY-HERE with your license key and give both PayloadUUID values fresh UUIDs.
  3. Upload the profile to your MDM (Jamf, Kandji, Mosyle, and others) and scope it to your Macs.

The profile sets the managed preference LicenseKey in the preference domain dev.petrmuselik.desco. Only a managed (forced) value is honored.

What to expect

  • Each Mac that activates uses one seat of the key; reinstalling on the same Mac reuses it.
  • Activation needs internet access to Dodo Payments once. If a Mac is offline at launch, Desco simply tries again on the next launch.
  • No dialog is shown to the user. Desco never locks because it is offline.
