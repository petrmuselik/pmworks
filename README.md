# PMWorks

Public home for **PMWorks** — focused Mac apps by Petr Muselík — and the community
around them (Discussions: bug reports, feature requests, Q&A).

- **Website:** https://petrmuselik.github.io/pmworks/ (custom domain planned)
- **Discussions:** https://github.com/petrmuselik/pmworks/discussions

## What's here

This repo holds **only** the public website and community — the static landing page
served via GitHub Pages. **No application source lives here.** Each product's source
is kept in its own (private) repository.

## Products

- **Desco** — a menu-bar manager for macOS Spaces: name and color your desktops and
  jump straight to them. *In development.*
- **Desco Lite** — a lighter take. *Planned.*

## Site

Plain static HTML/CSS (`index.html`, `style.css`), no build step. `.nojekyll`
disables Jekyll processing so the files are served as-is.
